# japanese-lessons

このプロジェクトでHTMLを作成・編集するときに従うべきルールと規則。

TRIGGER when: lesson HTML の作成・編集、joshi.html / リファレンスページの更新、スタイル変更

## 作成ルール（厳守）

- 学んだ内容のみ使用（未学習の文法・語彙は使わない）
- 新出漢字には読み方を括弧書きで記載（例：学生（がくせい））
- 過去レッスンで導入済みの漢字にはふりがな不要
- 文法説明は英語で書く
- 各課に漢字リスト・目次を含める
- 画像は assets/img/ 配下に `l{課}_image{番号}` で保存
- スライドの文言・構造を忠実に再現（勝手な追加・変更禁止）
- 変更が必要な場合は事前に確認
- 箇条書き→`<ul>`、番号付き→`<ol>`、ネスト構造はネストで再現

## HTMLの書き方ルール

- 各ページの h1 の上に `<a href="index.html">← 戻る</a>` を入れる
- h2 見出しは学習者が見てわかる形式にする（例：「〇〇が好きです」「〇〇で」）。メタ言語的なラベル（「助詞「が」」など）は使わない
- 各ページはこれまでの課と形式を揃える

## CSSクラスの使い方

- `.grammar-box`：セクションの核となる文法公式・文の説明に使う。箇条書き内の定義には使わない
- `.particle`：助詞のハイライト
- `.example`：例文
- `.kaiwa`：会話ブロック
- `.structure`：文構造（monospace）
- `.note`：注釈（灰色・小さめ）
- `.word-list`：単語リスト（flex wrap）
- `.table-wrap`：テーブルの横スクロール対応

## AI作業ルール

- スペルチェックの警告（固有名詞など）はユーザーに言及しない
