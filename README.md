# Japanese Lessons

日本語学習者向けの教材資料です。

## 準拠教材

みんなの日本語 第3版（初級I・II ＋ 中級）

- 初級I：第1課〜第25課
- 初級II：第26課〜第50課
- 中級：第1課〜（別冊）

※ファイル命名規則は未定。初級・中級・JLPTレベルの対応を考慮して後で整理する。

## 目標

JLPT N3

## レイアウト

- スタイルは `style.css` で調整する
- レスポンシブ対応必須

## 作成ルール

- 学んだ内容のみを使用する（未学習の文法・語彙は使わない）
- 新しく学ぶ漢字には読み方を括弧書きで記載する（例：学生（がくせい））
- 文法説明は英語で書く
- 各課に単語リストと漢字リストを含める
- 各ページに目次（もくじ）を入れる
