〇〇はきれいです

〇〇 は [adjective] です — Predicative pattern: describing 〇〇 directly
  • 桜（さくら）はきれいです。→ Cherry blossoms are beautiful.
  • あれはきれいじゃありません。→ That is not beautiful.
  • 町（まち）はにぎやかです。→ The town is lively.
  • あなたは美（うつく）しいです。→ You are beautiful.
  • あなたは健康（けんこう）です。→ You are healthy.

〇〇はきれいな〇〇です

〇〇 は [adjective + な] 〇〇 です — Attributive pattern: adjective modifies a noun
  • Add な to the end of the adjective when it comes before a noun.
  • 東京は有名（ゆうめい）な町です。→ Tokyo is a famous city.
  • 群馬は有名な町じゃないです。→ Gunma is not a famous city.
  • メキシコはにぎやかな国（くに）です。→ Mexico is a lively country.

These adjectives are called な形容詞（な-adjectives）.

  • Many な-adjectives originally function like nouns. （例：健康、大切（たいせつ）、元気（げんき））

〇〇は高いです

〇〇 は [い-adjective] です — same predicative pattern as きれい
  • 富士山（ふじさん）は高いです。→ Mt. Fuji is tall.
  • この車は高いです。→ This car is expensive.
  • ここは寒（さむ）いですか。→ Is it cold here?

However, the negative form is different from な-adjectives. The final い changes to く:

〜い → 〜くないです
  • この車は高くないです。→ This car is not expensive.
  • そこは寒くないです。→ It is not cold there.

〇〇は高い〇〇です

〇〇 は [い-adjective] 〇〇 です — い-adjectives modify nouns directly without 「な」
  • これは高い車です。→ This is an expensive car.
  • 寒い町です。→ It is a cold city.

These adjectives are called い形容詞（い-adjectives）.

  • If an adjective ends in 〜い, it is usually an い-adjective.
  • Exceptions to memorize for now: きれい and きらい — both end in い but are な-adjectives.

〇〇はどうですか

〇〇はどうですか — How is 〇〇? / What do you think of 〇〇?
  • Replace 〇〇 with a topic and answer with an adjective.
  • この車はどうですか。→ How is this car?
    • → この車は高いです。→ This car is expensive.
  • この町はどうですか。→ How is this city?
    • → この町はきれいです。→ This city is beautiful.
  • 日本はどうでしたか。→ How was Japan?
    • → 日本はしずかでした。→ Japan was quiet.
    • → 日本はしずかじゃなかったです。→ Japan was not quiet.
