第10課　あります・います・方向（ほうこう）

目次（もくじ）
  1. 〇〇があります
  2. 〇〇がいます
  3. 〇〇にあります・います
  4. 方向をあらわすことば
  5. Kanji List

〇〇があります

  • Used for non-living things — there is 〇〇 / 〇〇 exists
  • あそこに　コンビニが　あります。→ There is a convenience store over there.
    • ※ See Lesson 3 for how to use あそこ.
    • ※ See Lesson 7 for how to use に.

〇〇がいます

  • Used for living things (people, animals) — there is 〇〇
  • ロビーに　佐藤（さとう）さんが　います。→ Ms./Mr. Sato is in the lobby.
  • あそこに　だれが　いますか。→ Who is over there?
    • → あそこに　こどもが　います。→ There is a child over there.

〇〇にあります・います

  • Same meaning as 〇〇があります / 〇〇がいます, but used when the subject (topic) is stated first.
  • 東京（とうきょう）ディズニーランドは　千葉県（ちばけん）に　あります。→ Tokyo Disneyland is in Chiba Prefecture.
  • 家族（かぞく）は　ニューヨークに　います。→ My family is in New York.
  • 秋葉原（あきはばら）は　東京に　ありますか。→ Is Akihabara in Tokyo?
    • → はい、東京にあります。→ Yes, it is in Tokyo.

方向（ほうこう）をあらわすことば

  • となり next to
  • なか inside
  • まえ in front of
  • みぎ right
  • These words can be used on their own, or after a noun + の to describe position relative to something.
  • わたしは　となりに　います。→ I am next door.
  • 図書館（としょかん）は　カフェのとなりに　あります。→ The library is next to the café.
  • 私（わたし）の家（いえ）は右です。→ My house is on the right.
  • 箱（はこ）のなかは何（なに）ですか。→ What is inside the box?
